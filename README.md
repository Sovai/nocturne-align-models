# Nocturne Align Models

Versioned runtime assets for **Nocturne Studio's offline Khmer forced alignment**.

Large model files stay out of Git history. Runtime assets are published as GitHub Release assets and downloaded by Nocturne Studio into app-private storage.

## Current package

`kfa-fp32-v1` reproduces the acoustic/text stack used by `Sovai/nocturne-align`:

- `wav2vec2-km-base-1500.onnx` — Khmer Wav2Vec2 CTC acoustic model
- `g2p.fst` — Khmer grapheme-to-phoneme FST
- `khmercut.crfsuite` — Khmer word segmentation model
- `lexicon.tsv` — KFA lexicon converted from the upstream Python pickle into a portable runtime format
- `model-manifest.json` — immutable file URLs, byte sizes, SHA-256 hashes, and model metadata

The release is generated by the manual **Publish FP32 model** GitHub Actions workflow so every file and checksum is reproducible.

## Versioning

Release tags are immutable model contracts:

- `kfa-fp32-v1` — correctness baseline
- future `kfa-int8-vN` releases — validated quantized variants

Nocturne Studio pins an explicit release tag rather than `latest`, so a future release cannot silently change existing alignment behavior.
